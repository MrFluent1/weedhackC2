How Retrieval Works

  1. The browser and GitHub Action call eth_call on 0x1280a841Fbc1F883365d3C83122260E0b2995B74 with calldata 0xce6d41de.
  2. The returned ABI dynamic string is decoded by reading the offset word, length word, and payload bytes.
  3. The decoded text is split on |; the second field is also Base64-decoded when present.
  4. URLs and domains are extracted with regex and the scheduled workflow appends them to domains.log.
