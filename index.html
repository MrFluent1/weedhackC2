How Retrieval Works

  1. A scheduled GitHub Action calls eth_call on 0x1280a841Fbc1F883365d3C83122260E0b2995B74 with calldata 0xce6d41de.
  2. The returned ABI dynamic string is decoded by reading the offset word, length word, and payload bytes.
  3. The second |-separated field is treated as signature metadata; only its validity, length, and SHA-256 hash are stored.
  4. Domains are normalized, de-duplicated, and committed to static JSON/log files consumed by this page.
